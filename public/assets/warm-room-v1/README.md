# 暖调房间首套素材 v1

通过内置 imagegen 生成，非 MiMo 图片输出。全部图片1536×1024；背景RGB，其余五张为实际带alpha的RGBA PNG。未裁切，加载时注意透明留白，不能按整张图片宽度估算物体尺寸。

## 文件

- room_warm_01.png：房间底图，包含两面墙、木地板、窗外自然景观、书架、植物/陶罐装饰、边桌与唯一台灯。这些固定家具可添加点击热区，不可从背景独立移动。
- armchair_sage_01.png：可独立摆放的扶手椅。
- cat_orange_01.png：坐姿橘白猫。
- memory_shell_01.png / memory_frame_01.png / memory_letter_01.png：三件可独立隐藏、收集的纪念物。
- manifest.json：ID、像素尺寸、alpha范围。
- prompts.json：完整固定前缀、任务后缀、负面提示及边缘清理提示词。
- preview.html：离线叠放草图及素材浏览，不是Phaser成品。

## 范围与检查

固定白天暖光，本轮没有生成昼夜三套背景。独立素材未经像素重绘，保留生成alpha。已检查各文件可解码及实际透明通道，完成可见图像人工检查；仍需在Phaser实际画幅进行比例、接触阴影、相机一致性验收。

所有独立素材的相机提示一致，但生成图片不能保证严格数值校准。猫较接近写实毛发，和房间最终风格匹配仍待用户审阅。宽松缩放可用，不应水平翻转素材以免改变受光方向。

本轮无Blender源文件，不能验证灯罩内部实际离线光源、真实正交相机或物理材质参数。需要严格这些条件时应改用Blender源场景统一渲染；无需用户手写建模代码。建议相机orthographic，方位45°、俯角35.264°作为起点，统一米制尺度，固定窗光方向和暖色台灯，分别导出背景与带alpha的对象pass。
