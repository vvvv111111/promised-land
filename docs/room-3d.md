# 3D 房间样版

地址：`/room-3d`。独立预览页，尚未替换现有首页与八页礼物流程。用户认可整体 3D 效果并继续调整细节；本轮取消物品拖动摆放，并加入 CD 机与已有音乐/录音文件上传。

房间现在由 `src/room/default-room.json` 驱动，模型、组装和镜头分别位于 `src/room/models`、`buildRoom.ts`、`rendering`。代码职责、数据流与后续 Agent 接口边界见 [代码整理说明](code-organization.md)。本次拆分不改变现有画面和操作。

## 本轮范围

- Three.js 本地依赖，客户端动态加载。房间、窗洞、家具、生活用品均由网格几何构成，具有实际厚度、遮挡和光照；没有使用房间背景图或面向镜头的物品贴片。
- 自然色的起居室样版，包含双人沙发、茶桌、低柜、窗户、织物、茶杯、书、植物和猫。没有独立小扶手椅、光尘或摆放区域辅助线。
- 鼠标或单指拖动旋转，滚轮/双指缩放；提供放大、缩小、复位和键盘操作。镜头限制在房间开放一侧，可查看物品侧面；尚未提供第一人称行走。
- 相框、信件、台灯、CD 机使用 3D 射线命中和明确的回调。转动和双指操作不会触发点击；墙体和家具会遮挡后面的物品。
- 点击交互物品或其键盘按钮，镜头根据实际模型包围盒拉近。内容在桌面右侧或手机底部显示，镜头根据面板实际尺寸重新取景，保证放大的物品可见。关闭内容后返回点击前的镜头位置与缩放；台灯提供「返回房间」。镜头动画遵循减少动态效果设置，不移动物品。
- 相框和信件通过 `openWinterGift` 只读取得当前浏览器的完整礼物数据，复用原有内容弹窗；相框纹理使用同一照片、4:3 取景比例和取景参数。本页不会保存礼物、摆放或收集进度。
- 台灯切换场景中的真实光源。模型不自动转动；静止时停止请求新帧，离开页面时释放控制器、监听器、几何体、材质、纹理及 WebGL 上下文。
- 不支持 WebGL 2 或上下文丢失时显示失败提示和重试入口。

## CD 机与音频

茶桌上的 CD 机由机身、碟片、透明盖、按钮和扬声器孔构成；点击打开播放器，播放时指示屏改变状态。

默认制作模式支持上传已有音乐或录音文件（20MB 以内），先试听、明确保存，再播放/暂停或调整进度；关闭面板后已保存的音频可继续播放，离开页面停止。`?mode=recipient` 只允许播放，不显示上传、保存或移除入口。不提供麦克风录音。

音频以 `giftId` 为键，完整存入 `promised-land-room-audio` IndexedDB 的单条记录（Blob、文件名和更新时间），这是音频唯一来源；不在 localStorage 中复制音频或元数据，不改动照片和信件的 GiftStore 保存。写事务提交后才更新界面记录，替换失败时旧 Blob 和元数据一同保留。当前 3D 页仍使用 `winter-local-v1` 礼物。分享/服务端接入时需要另行接入音频资源存储。

检查文件大小、容器签名及当前浏览器实际解码能力，拒绝损坏、伪装或无法播放的文件。退出、替换或放弃试听时释放 Object URL。仅保存在此浏览器，清理网站数据会丢失。

现有 2D 房间也已取消物品拖动、位置写入和恢复默认摆放；旧位置缓存被忽略，不在初始化时重写。历史摆放算法仍用于默认落点与遮挡、状态回归资料，不代表保留用户摆放功能。

## 验证

```powershell
npm run typecheck
npm run build
npm test
```

`npm test` 汇总现有状态测试与新增房间数据、模型组装/资源释放、照片处理策略测试。

浏览器验收：`scripts/check-room-3d-browser.cjs`，沿用现有可选 Playwright、`ROOM_CHROMIUM` 和 `ROOM_URL` 配置，检查镜头、实际模型点击、礼物只读、台灯、重新挂载、手机双指操作和 WebGL 不可用时的提示。截图存于 Git 忽略的 `.room-qa/`。

`check-room-audio-browser.cjs` 使用真实 WAV 检查原生 CD 模型命中、试听/保存/播放、面板关闭后播放、刷新恢复、非法/超大文件、写入成功后提交前中止的回退、只读模式、替换和移除。`check-room-fixed-browser.cjs` 检查鼠标和手机拖动不再移动物品、不触发点击或位置写入，旧位置缓存不再影响画面。

`check-room-focus-state.cjs` 检查物体完整进入面板外的可视区、动态面板尺寸、镜头精确恢复、物品保持固定和动画中断。`check-room-focus-browser.cjs` 检查真实放大画面、手机点按、按钮入口、关闭恢复手动缩放、正常/减少动态效果及动画中关闭。镜头功能独立在 `objectFocus.ts`，面板通过明确的布局回调报告尺寸，不读取文案或模拟点击。

## 待确认与未接入

这是程序建模的空间与交互样版，家具与材质细节仍待调整。未将 3D 替换进现有送礼流程，未实现 3D 纪念物收集、第一人称行走、分享服务或真实生成。物品拖动摆放已按用户要求取消，不列入后续任务。手机手势使用 Chrome 模拟验证，真机性能、音频格式兼容和手感仍需验收。
