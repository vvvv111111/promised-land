# 2.5D 物理摆放与投影

当前素材接近等距/正交视角，因此物品移动时保持原始比例和配置尺寸。没有根据屏幕 Y 随意放大缩小；通过标定支撑平面、物体底部接触点、占地和遮挡处理空间关系。生成图片的相机没有严格数值标定，当前为近似校准。

## 配置

`demo-world.json` 的 `placement` 包含：

- `version`：摆放规则版本；升级后旧的摆放缓存失效，避免重新恢复到墙上或房间外。
- `projection: orthographic`：当前图片的投影约定。
- `surfaces`：真实支撑面，包括 floor、side-table-top。polygon 为背景归一化四角，按后、右、前、左排序。
- `blockers`：同一支撑面的固定家具占地。地板有书架和边桌占地，桌面有台灯底座占地。
- `depth_y`：桌面关联的固定家具深度，使桌面小物件位于桌面前方，但仍可被更靠前的大物体遮挡。
- `occluders`：用原始背景的同一纹理和多边形遮罩重绘固定家具前景；不生成或改写队友素材。台灯单独按桌面落点处理前后关系。

每件物体的 `placement` 包含：

```json
{
  "contact": { "x": 0.5, "y": 0.84 },
  "footprint": { "width": 0.09, "depth": 0.08 },
  "surfaces": ["floor"]
}
```

contact 是完整 PNG 中的底部地面接触中心，不等同于 PNG 底边或其透明包围盒。footprint 是沿地面两条投影轴的占地长度，以背景宽度作为尺度。图片主体可以与别的物体在屏幕上重叠，这属于正常遮挡；地面占地不允许穿插。

猫和扶手椅仅允许在地板上。贝壳、相框、信件允许在地板或边桌上，但仍必须有足够的占地空间，不能压住台灯或互相重叠。边桌容量有限，不能保证所有小物件同时放得下。

## 算法

`src/world/RoomPlacement.ts` 独立于 Phaser：

1. 四角单应映射在房间平面坐标与背景坐标之间转换。
2. 将整个占地投影到支撑面；按凸多边形半平面约束，避免悬空、穿墙或超出地板边缘。
3. 使用 SAT 检测固定与可移动占地，移动分成小步扫描；遇到阻挡时停止或沿边滑动，防止快速拖动跨过家具。
4. 只有小物件可切换到桌面支撑。此时代表赠送者用手将它放上桌面，不是从地板自行爬升。
5. 以实际落地点而非图片锚点排序，桌面物品使用支撑面的深度。
6. 恢复时同时移除待恢复物品的默认占地，再逐个恢复，允许有效的位置交换。失效位置会校正到合法支撑面。

Scene 只负责显示模型给出的结果。被固定家具前景遮住的像素不能截获点击，点击会交给真正可见的家具。松手时再次计算最终坐标，避免最后一次移动发生在两帧之间而漏掉桌面落点。

## 边界

这是编辑摆放约束，不是重力、摩擦、弹跳或刚体倾倒模拟。地面、占地和遮挡轮廓按当前图片人工标定；更换房间图片时必须重新标定。PNG 已烘焙的受光、阴影、相机视角无法通过平移严格统一；当前没有重新绘制素材，也没有让独立物品合并进背景。
